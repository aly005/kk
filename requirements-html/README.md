# GUC PortfolioHub — Requirements 21–38

HTML prototype pages for functional requirements 21–38 of the Project Portfolio Web Platform.

## Files

| File | Requirements |
|---|---|
| `index.html` | Navigation index page |
| `student-projects.html` | Req 21 — View projects list, Req 22 — Portfolio visibility toggle |
| `thesis.html` | Req 23 — Upload thesis drafts, Req 24 — Select Final Draft |
| `collaborators.html` | Req 25 — Search collaborators, Req 26 — Send/cancel invitations, Req 27 — View invitation status, Req 31 — Remove collaborator |
| `invitations.html` | Req 28 — Invitation notifications, Req 29 — View invitations list, Req 30 — Accept/Reject invitations |
| `tasks.html` | Req 32 — Create/edit/delete tasks, Req 33 — View task list, Req 34 — Reorder tasks |
| `notifications.html` | Req 35 — View notifications, Req 36 — Mark read/unread |
| `instructor-feedback.html` | Req 37 — Task feedback, Req 38 — Project/thesis feedback |

## How to Run

Open any `.html` file directly in your browser — no server or installation needed.

Start from `index.html` for a navigation overview of all pages.

## Notes

- All data is hard-coded dummy data (no backend required).
- Built to match the design language of the existing MAAAA React project.
